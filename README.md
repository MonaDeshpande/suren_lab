# S Testing Laboratory Customer Test Request App

Streamlit + PostgreSQL application for **S Testing Laboratory**.

## Features

- **Login & roles** — admin, reception, analyst, reviewer (one role per user)
- **Reception** — Customer Test Request form, permanent customer master (GST), filled PDF/Word
- **Auto sample codes** — each sample gets `SLS-YYMMDD-NNNN` for analyst handoff
- **Analyst** — protocol worksheets, calculations, protocol PDF/DOCX, status updates
- **Reviewer** — review reception + analyst data, generate **Final Test Report** PDF (QSF 7.8.2)
- **Admin** — register users, assign/change roles, reset temporary passwords; view audit log
- **Audit trail** — every create/update/delete records who, when, and what in `audit_log`
- **Report stamps** — CTR / Protocol / Final Test Report show Generated by + date/time; reviewer signs with pen
- **10-day retention** — sample rows expire and are cleaned up; customers stay permanent

## Quick start

```bash
# 1. Env file (defaults: 127.0.0.1:5433)
copy .env.example .env

# 2. Start PostgreSQL in Docker
docker compose up -d

# 3. If the DB volume already existed, apply migrations as needed:
docker exec -i sls_lab_db psql -U sls_user -d sls_lab < scripts/migrate_samples.sql
docker exec -i sls_lab_db psql -U sls_user -d sls_lab < scripts/migrate_auth.sql
docker exec -i sls_lab_db psql -U sls_user -d sls_lab < scripts/migrate_protocol.sql
docker exec -i sls_lab_db psql -U sls_user -d sls_lab < scripts/migrate_audit.sql

# 4. Install deps, seed default admin, run
pip install -r requirements.txt
python scripts/seed_admin.py
streamlit run app.py
```

Or double-click `run_app.bat` (after `seed_admin.py` once).

Open http://localhost:8501 and sign in.

## Sample workflow

```
Admin creates user accounts (reception / analyst / reviewer)
    → staff change temp password at desk
Reception saves CTR
    → one DB row per sample + sample_code + tests_to_perform
    → expires_at = now + 10 days
Analyst opens sample_code
    → protocol + calculations → status completed
Reviewer opens sample
    → reviews reception + analyst data
    → Generate Final Report PDF → status reported
Cleanup (auto on app open, or manual):
    python scripts/cleanup_expired_samples.py
```

## Permanent vs sample data

| Permanent (`customers`) | 10-day samples (`request_samples`) |
|-------------------------|--------------------------------------|
| Name, address, contact, email, GST | sample_code, tests, status, remarks |
| Kept forever | Deleted after `expires_at` |

CTR headers (`test_requests`) are kept for audit; only expired **sample** rows are removed.

Users (`users`) are permanent login accounts.

## Analyst protocol (shared 11-test library)

Reception selects catalog tests (Moisture, ash, sugars, …). Those formulas are
**shared** — any sample name that selects Moisture gets the same worksheet.

Analyst page: protocol header → Appearance → per-test inputs/formula → page-1
results → Generate protocol PDF/DOCX. Status: pending → in_progress → completed.

**Reviewer** generates the customer Test Report PDF (QSF 7.8.2) and sets status to
`reported`.

Empty required fields show a **popup**. Run once if upgrading an existing DB:

```bat
docker exec -i sls_lab_db psql -U sls_user -d sls_lab < scripts/migrate_protocol.sql
python scripts/seed_admin.py
```
